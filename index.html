System capabilities

Everything currently available

Launch utility →
⇄

Java ↔ Bedrock Conversion

One direction-aware input for Java ZIPs and Bedrock MCPACK/ZIP resource packs with architecture verification before conversion.

⌁

Architecture Detection

Recognizes vanilla resource packs plus supported ItemsAdder, Nexo, and Oraxen source/vendor layouts.

◆

Custom Item Mapping

Handles modern ItemModel definitions, legacy CustomModelData, range dispatch, conditions, selects, and Geyser custom mappings.

A

Fonts & Glyph Atlases

Maps Java bitmap font images into Bedrock glyph pages, restores Bedrock glyph cells into Java providers, and displays Unicode/page/slot data.

▦

Full Glyph Page Viewer

Inspect a complete 16×16 glyph atlas with 00–FF slot overlays and verify exactly where each private-use character lands.

✥

Mapping Correction Editor

Click editable conversion rows, drag textures, resize from four corners, and save corrections directly back into the final archive.

G

Geyser Integration

Generate Bedrock item textures, custom mapping JSON, setup guidance, and downloadable mapping artifacts for Java/Bedrock cross-play.

IA

Plugin Pack Support

Supports ItemsAdder contents layouts, ItemsAdder data/items_packs layouts, Nexo pack/assets, and Oraxen pack structures.

⌘

Process Console

Follow scanning, mapping, packaging, warnings, fallbacks, and unresolved data through a live conversion log.

◫

Visual Result Browser

Review source and output textures side-by-side by blocks, items, mobs, fonts, GUI, environment, and other images.

✓

Transparent Fallbacks

Unsupported or uncertain mappings are reported instead of being silently presented as successful conversions.

⌂

Local Browser Processing

Pack processing, preview storage, and manual edits stay in the browser rather than being uploaded to a Dazen conversion server.
